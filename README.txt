BLESSING LAWRENCE — COMPLETE STUDENT PORTFOLIO

FILES
index.html       Home page
about.html       Biography, education, career goal, skills and interests
projects.html    Three sample project descriptions
planner.html     Interactive academic task planner
contact.html     Contact details and validated contact form
css/style.css    External responsive stylesheet
js/main.js       Mobile navigation and footer year
js/planner.js    Add, complete, delete and clear tasks
js/contact.js    Contact form validation

HOW TO RUN
1. Extract this ZIP file.
2. Keep the folders and files in their current structure.
3. Open index.html in a web browser.
4. Edit the files using Visual Studio Code or another code editor.

NOTES
- Planner tasks are saved in local storage in the current browser.
- Contact form validation works, but messages are not sent. A backend or form service is needed for submissions.
- Project descriptions are sample concepts. Replace them with your actual work and links.
- Add your institution, level, certificates, and a suitable personal photo if required.
- The assignment PDF also asks for a table and multimedia (audio or video). Add those elements if your instructor expects every listed requirement.

PERSONAL PHOTO
The uploaded portrait is displayed on the home page from assets/blessing-lawrence.png. Keep the assets folder in place.
